# UP9-Dise-o-de-API-REST-para-tu-sistema-de-reservas
Diseño de una API REST para el proyecto intermodular

## Enunciado Aules
Actividad intermodular: Diseño de API REST para tu sistema de reservas. A partir del diseño de base de datos del proyecto intermodular, documentarás el contrato entre frontend y backend mediante una especificación OpenAPI 3.0 con ejemplos JSON y documentación Swagger UI. Obligatoria para todos los matriculados en LMSGI — si no tienes proyecto intermodular, consulta la sección de Preguntas Frecuentes del enunciado: encontrarás un diseño de BBDD mínimo (sistema AENA) con el que puedes completar la actividad.

Tarea disponible en el siguiente enlace:  https://github.com/scontreraslopez/lmsgi-2025-public/blob/main/UP09/actividad-proyecto-intermodular.md

A la hora de entregar, copiarme el ENLACE a vuestro repositorio de github donde yo pueda encontrar la solución. Con eso yo lo clono y puedo evaluarlo. ¡Gracias!
